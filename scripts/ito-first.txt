# Crates an app must not depend on directly, because an ito crate already does
# that job for every uchmk app. `scripts/ito-first.py` fails when a workspace
# member lists one of these (in [dependencies], [dev-dependencies] or
# [build-dependencies]); a crate that is only a transitive dependency is fine.
#
# One line: <crate> <ito crate and what to use instead>. Add a line when ito
# gains a crate that replaces a dependency (and say so in CHANGELOG.md).
#
# An app that has a reason to keep one lists it, with the reason, in its own
# scripts/ito-first.allow (same shape: `<crate> <why ito's does not do>`). If
# ito's crate lacks something, ask ito for it (an issue in uchmk/ito) first.
